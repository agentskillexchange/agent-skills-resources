# Diagrams

Use these framework-neutral maps when you want the repo's learning path as a
visual model before reading the detailed guides.

## Start With The Visitor Workflow

The practical path is
[Learn -> Draft -> Review -> Evaluate -> Pilot](../docs-index.md#visitor-workflow-map).
Use that workflow map when you want to move from a first visit to a reviewable
skill draft and a bounded team pilot.
